Trabajo Práctico Integrador N° III

Desarrollo desde cero de una API REST para gestionar usuarios, eventos y categorías, usando
MongoDB como base de datos NoSQL y Mongoose como ODM. Aplicamos todas las tecnologías vistas en clase: JWT, cookies, bcrypt, validaciones con express-validator, relaciones embebidas y referenciadas, virtual populate y operaciones CRUD completas con eliminación lógica y en cascada.
